# Dropping macOS

**Status:** done, 2026-10-26.
**Applies to:** the support claim, the two `macos-latest` CI jobs, every Darwin branch.

## Why

Nobody owns a Mac. The support claim was honest about that -- "CI-tested, not
daily-driven", exactly as strong as `link only (macos)` and `install (macos /
brew)` -- and the cost was not the runner minutes. It was the rule those jobs
imposed on every change: prefer the construct BSD userland can run, keep the
install path bash-3.2-clean, carry a brew cask next to every font download. A
tax paid on every edit, for a machine that does not exist, is the wrong
trade even when each payment is small.

## What went

- CI: the `macos` leg of `link only`, the `macos / brew` leg of `install`,
  the "no bash 4+ constructs on the 3.2 path" grep, the `Cellar` provenance
  arm in the uv check. Both removed jobs were **required status checks** in
  the `main-branch-rules` ruleset and were removed there in the same change;
  a required check that never reports does not fail a PR, it blocks it.
- `lib/pkg.sh`: the Darwin branch of `pkg_detect`. brew stays as the last
  resort after apt and dnf, because linuxbrew is real on RHEL boxes.
- `bash/bashrc`: `_OS`, the osascript `alert`, the `/opt/homebrew` shellenv,
  the `java_home` branch. `bash/deps.sh`: bash 5 via brew.
- `wezterm/deps.sh`: three `brew install --cask font-*` blocks and the
  `brew install --cask wezterm` hint. `nvim/deps.sh`: the lemminx `osx`
  asset and `pngpaste`. `nvim/lua/external/pasteimg.lua`: the `save_macos`
  backend. `health.lua`: its check.
- `Makefile`: the Darwin half of `make shell` (dscl, `/etc/shells`, a brew
  bash). The Linux half now goes through `sudo chsh` so the target still
  escalates and `dots` still detaches it -- see the comment on the recipe.
- `install.sh`: the "your default shell is zsh" note.

## What stayed, and why

Constructs that were written for bash 3.2 or BSD userland and cost nothing:
the global-plus-read-loop in `lib/manifest.sh`, the guarded `readlink -f`
fallbacks, `COPYFILE_DISABLE` on the compress path (archives made on a Mac
still arrive here), the `BASH_VERSINFO` guards in bashrc. Each comment now
says it is history rather than a requirement.

`mise.lock` still carries darwin checksums. It is generated by `mise lock`,
which writes every platform it knows; the entries are inert and the next
`make mise-lock` decides what it writes.

`lsp_servers.lua` still maps `Darwin` to TypeScript's `darwin` binary. It is
a lookup table, not a code path, and removing a row would turn "unsupported"
into "silently nil" for no gain.

## To bring it back

Restore the two matrix legs and add them back to the ruleset; re-add a
Darwin branch to `pkg_detect`; put the three casks back in `wezterm/deps.sh`;
re-add the `save_macos` backend. The 3.2 grep should come back only if a
fresh Mac's `/bin/bash` is on the install path again. The diff that removed
all of it is the one commit on 2026-10-26 titled "drop macOS".
