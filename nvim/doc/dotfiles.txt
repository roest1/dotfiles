*dotfiles.txt*    Everything this nvim config adds, on one page

==============================================================================
THIS CONFIG                                                          *dotfiles*

Leader is <Space>. This page lists only what this config adds or changes.
Vim itself (motions, operators, registers) is in the built-in help:
|motion.txt|, |operator|, |text-objects|. The shell is `h` in a terminal.

CI checks this page against the config in both directions: a mapping or
command and its line here change in the same commit.

==============================================================================
KEYS                                                            *dotfiles-keys*

Move around~
    -               Open the file browser (oil) on the current directory
    <leader>-       The same, in a floating window
    <leader>sf      Search files by name
    <leader>sg      Search text inside files, typed literally
    <C-h/j/k/l>     Move to the split on that side
    L               End of line

Both searches cover the repo that holds what you are looking at (the oil
directory or the current file), hidden files included; the prompt title says
where. Grep reads what you type as plain text, so `setup(` and `[nvim]` find
exactly that. Inside the grep prompt, <C-e> switches to regex and back.

Inside oil~
    <CR>            Open the file or directory
    -               Up one directory
    g?              Oil's own key list
Edit the listing like text to rename, delete or create files; :w applies it.
The +N -N at the right edge is each file's change since the last commit.

Code~
    grd             Go to definition
    grr             List references
    gri             List implementations
    grt             Go to type definition
    grD             Go to declaration
    grn             Rename (nvim's own key)
    gra             Code action, including a linter's suggested fix
    K               Hover documentation (nvim's own key)
    gO              Symbols in this file
    gW              Symbols in the project
    ]c  [c          Next / previous git change in the file
    <leader>l       Format the file, or the selection in visual mode
These need a language server attached; `:checkhealth vim.lsp` says which is.

Completion~
    The popup opens by itself after the characters a server asks for, such
    as `.` or `::`.
    <C-x><C-o>      Open it anywhere (insert mode)
    <C-n>  <C-p>    Next / previous item
    <C-y>           Accept
    <C-e>           Dismiss

Small things~
    <Esc>           Clear search highlighting
    :%y             Yank the whole buffer to the system clipboard

COMMANDS                                                    *dotfiles-commands*

                                                                        *:Copy*
:Copy               Copy file contents to the clipboard, each wrapped in
                    start/end markers, for pasting into a chat.
    :Copy               every file in the current directory
    :Copy -r            the same, with subdirectories
    :Copy --ext=lua     only that extension; --ext={lua,py} for several
    V then :Copy        in oil: the selected files
                        in a file: the selected lines, with path and range
Respects .gitignore and skips binary files.

                                                           *:Find* *:FindReplace*
:Find {word}        Load every file containing {word} into the argument
                    list; :next and :prev walk it.
:FindReplace {old} {new}
                    Replace across those files, asking at each match
                    (y yes, n no, a all in this file, q quit). No spaces in
                    either argument; {old} is a Vim regex.

                                                                  *:PasteImage*
:PasteImage         Save the image on the clipboard as a PNG in the directory
                    oil is showing (or next to the current file).
                    `:PasteImage --rename name.png` names it.

                                                                  *:YankBuffer*
:YankBuffer         What :%y runs.

                                                                      *:OilGit*
:OilGit             Turn the +N -N column in oil off or on.

                                                                     *:AltFont*
:AltFont            Say whether files are being drawn in the editor font, and
                    why not if not. `:AltFont toggle` turns it off until exit.

                                                                 *:KeymapUsage*
:KeymapUsage        Every mapping and command with how often you used it,
                    never-used first. `:KeymapUsage reset` starts over.

WHAT HAPPENS ON ITS OWN                                         *dotfiles-auto*

    Saving          :w formats the file first (stylua, prettier, ruff, or the
                    language server) and puts the cursor back.
    Yanking         The text flashes and a message says how much was copied.
                    Yanks go to the system clipboard.
    Images, PDFs    Opening one launches the desktop viewer instead of
                    loading bytes. `:noautocmd e file.pdf` loads it anyway.
    Symbols         Resting the cursor on a name highlights its other uses.
    Undo            History survives closing the file.
    Quitting        :q with unsaved changes asks instead of failing.

==============================================================================
LOOKS                                                          *dotfiles-looks*

Two lanes, colored and typeset separately:
    ui              oil, telescope, floats, the gutter and the statusline
    editor          windows showing a file you write

Colors come from ~/.config/dotfiles/theme.conf (per machine, optional):
    nvim.ui.colors           = rose-pine-moon
    nvim.ui.transparent      = true
    nvim.editor.colors       = onedark
    nvim.editor.transparent  = false
No file means rose-pine-moon, transparent, in both. dracula and onedark are
installed. An editor key left out follows the ui lane.

Pick them with `font` in a terminal, on its Colors tab. A pick applies at
once, in every nvim that is running.

The editor lane's font is picked there too, on the Fonts tab. It only works
inside WezTerm running this repo's config; |:AltFont| reports on it.

==============================================================================
UPKEEP                                                        *dotfiles-upkeep*

    :lua vim.pack.update()  Plugins: fetch what is new and show it. :write
                            accepts, :quit refuses. Then commit
                            nvim-pack-lock.json, which is what puts every
                            machine on the same plugin code.
    :checkhealth external   Are the tools this config needs installed, and
                            which language servers are off for lack of one
    make -C nvim sync       Put plugins on the lockfile's commits and remove
                            any no longer listed (terminal)

Language servers are installed by the dotfiles repo, not from inside nvim:
`make install nvim` in the repo root.
