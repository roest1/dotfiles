*dotfiles-keymaps.txt*    Complete Keymap Reference

==============================================================================
KEYMAPS                                                        *dotfiles-keymaps*

Every mapping this config defines. Leader is <Space>. If a key is not on
this page, it is Vim's own -- see |motion.txt|, |operator|, |windows.txt|.

This file is checked by CI in both directions: every <leader> key named here
must be defined under lua/, and every <leader> key defined under lua/ must be
named here. Edit the mapping and the line below it in the same commit.

:KeymapUsage shows how often each of these has actually been pressed; see
|dotfiles-commands-usage|.

==============================================================================
CORE                                                      *dotfiles-keymaps-core*

Location: lua/keymaps.lua

    L               End of line (`$`), in normal and visual mode
    <Esc>           Clear search highlight
    <C-h>           Move to left split
    <C-j>           Move to lower split
    <C-k>           Move to upper split
    <C-l>           Move to right split

    :%y             Yank the whole buffer to the system clipboard (OSC52)

==============================================================================
SEARCH - TELESCOPE                                   *dotfiles-keymaps-telescope*

Location: lua/external/plugins/telescope.lua

    <leader>sf      [S]earch [F]iles in project
    <leader>sg      [S]earch by [G]rep (text in files)

<leader>s is the one which-key group: press it and wait for the popup.

Everything else telescope can do is a command: `:Telescope help_tags`,
`:Telescope keymaps`, `:Telescope buffers`, `:Telescope resume`. They were
mapped once and the mappings were deleted in 37fa6ce; add one back only when
you catch yourself typing the command.

Inside Telescope:
    <CR>            Select item
    <C-x>           Open in horizontal split
    <C-v>           Open in vertical split
    <C-/>           Show keymaps (insert mode), ? in normal mode
    <Esc>           Close

==============================================================================
WORKING SET - HARPOON                                  *dotfiles-keymaps-harpoon*

Location: lua/external/plugins/harpoon.lua

    <leader>a       Add current file to the list
    <C-e>           Open the quick menu (edit the list as a buffer)
    <C-n>           Next file in the list
    <C-p>           Previous file in the list

See |dotfiles-harpoon| for the workflow.

==============================================================================
FILE BROWSER - OIL                                        *dotfiles-keymaps-oil*

Location: lua/external/plugins/oil.lua

    -               Open parent directory
    <leader>-       Open parent directory in a floating window

Inside Oil:
    <CR>            Open file / enter directory
    -               Go up one directory
    g?              Show Oil's own keymaps
    <C-c>           Close

Rename, delete and create by editing the buffer and saving. See
|dotfiles-plugins-oil| for :OilGit, :OilColumns and what <CR> does on a PDF.

==============================================================================
LSP                                                        *dotfiles-keymaps-lsp*

Location: lua/external/plugins/lsp.lua. Buffer-local; set when a server
attaches.

    grd             [G]o to [D]efinition
    grD             [G]o to [D]eclaration
    grr             [G]o to [R]eferences
    gri             [G]o to [I]mplementation
    grt             [G]o to [T]ype definition
    grn             [R]e[n]ame symbol
    gra             Code [A]ction (normal and visual)
    gO              Document symbols
    gW              Workspace symbols

    <C-t>           Jump back after a goto (Vim's tag stack)

Diagnostics use Neovim's own defaults: `]d` / `[d` to move between them,
`<C-w>d` to float the one under the cursor, `:Trouble diagnostics` for a list.

==============================================================================
GIT - GITSIGNS                                        *dotfiles-keymaps-gitsigns*

Location: lua/external/plugins/gitsigns.lua

    ]c              Next hunk
    [c              Previous hunk

Staging, blame and preview are commands: `:Gitsigns stage_hunk`,
`:Gitsigns blame_line`, `:Gitsigns preview_hunk`. The leader-h family that
wrapped them was deleted in 37fa6ce.

==============================================================================
FORMATTING                                          *dotfiles-keymaps-formatting*

Location: lua/external/plugins/formatter.lua

    <leader>l       Format file, or the selection in visual mode

Saving also formats: a BufWritePre autocmd in lua/options.lua, NOT conform's
own `format_on_save`, because it saves and restores the cursor and conform's
option does not. <leader>l is the only way to format a selection.

Formatters by filetype are listed in |dotfiles-plugins-formatter|.

==============================================================================
SURROUND - MINI                                          *dotfiles-keymaps-mini*

Location: lua/external/plugins/mini.lua

    sa{motion}{char}    Add surrounding      saiw"  -> "word"
    sd{char}            Delete surrounding   sd"    -> word
    sr{old}{new}        Replace surrounding  sr"'   -> 'word'
    sf / sF             Find next / previous surrounding
    sh                  Highlight surrounding
    sn                  Set how many lines sf/sF search

==============================================================================
TODO COMMENTS                                            *dotfiles-keymaps-todo*

Location: lua/external/plugins/todo-comments.lua

    ]t              Next TODO / FIXME / NOTE comment
    [t              Previous one

`:TodoTelescope` lists them all.
