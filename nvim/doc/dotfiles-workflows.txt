*dotfiles-workflows.txt*    Common Tasks and Workflows

==============================================================================
WORKFLOWS                                                    *dotfiles-workflows*

"How do I..." recipes, using only keys this config defines plus Vim's own.
Where a recipe names a command rather than a key, that is deliberate: the
mapping was deleted in 37fa6ce and has not been missed enough to come back.

==============================================================================
FINDING FILES                                        *dotfiles-workflows-finding*

Find a file by name:~
    <leader>sf -> type filename -> <CR>

Find a file containing specific text:~
    <leader>sg -> type search term -> <CR>

Find where a function is defined:~
    Cursor on the name -> grd

Find everywhere a function is used:~
    Cursor on the name -> grr

Switch between open buffers:~
    :Telescope buffers      (or :ls and :b <n>)

Find a file I had open recently:~
    :Telescope oldfiles

Repeat the last picker:~
    :Telescope resume

Replace in the current file, one match at a time:~
    /pattern -> cgn<replacement><Esc> -> . to repeat, n to skip

==============================================================================
NAVIGATING CODE                                    *dotfiles-workflows-navigating*

Jump to where something is defined:~
    Cursor on symbol -> grd
    To jump back: <C-t>

Jump to the type of a variable:~
    Cursor on variable -> grt

See all references to something:~
    Cursor on symbol -> grr

See all functions/classes in file:~
    gO -> select from list

See all symbols in project:~
    gW -> type to filter

==============================================================================
EDITING CODE                                          *dotfiles-workflows-editing*

Rename a variable everywhere:~
    Cursor on variable -> grn -> type new name -> <CR>

Fix an error (quick fix):~
    Cursor on error -> gra -> select fix

Format the file:~
    <leader>l (or just save -- a BufWritePre autocmd formats too)

Format only a selection:~
    Select in visual mode -> <leader>l

Change the quotes around a string:~
    sr"'            (mini.surround: replace " with ')

Comment out lines:~
    Select lines in visual mode -> gc (Neovim's built-in commenting)

Indent multiple lines:~
    Select in visual mode -> > (repeat with .)
    Or: << and >> in normal mode

==============================================================================
WORKING WITH FILES                                      *dotfiles-workflows-files*

Create a new file:~
    - (open Oil) -> type filename on blank line -> :w

Rename a file:~
    - (open Oil) -> edit the filename -> :w

Delete a file:~
    - (open Oil) -> dd on the line -> :w

Copy directory contents to clipboard (for AI/docs):~
    - (open Oil in directory) -> :Copy
    Recursive: :Copy -r
    Exclude: :Copy --exclude=node_modules

Paste a screenshot into a directory:~
    - (open Oil there) -> :PasteImage

==============================================================================
WORKING SET (HARPOON)                                  *dotfiles-workflows-harpoon*

Start a new task with specific files:~
    1. Open each file you need
    2. <leader>a on each one
    3. Now <C-n>/<C-p> cycles through just those

Reorder, remove, or clear the set:~
    <C-e> -> edit the lines -> close the menu

==============================================================================
GIT WORKFLOWS                                            *dotfiles-workflows-git*

Navigate between changes:~
    ]c (next) and [c (previous)

See what I changed on this line:~
    :Gitsigns preview_hunk

Stage just this hunk:~
    ]c to reach it -> :Gitsigns stage_hunk

See who wrote a line:~
    :Gitsigns blame_line

See which files changed, with counts, while browsing:~
    - (open Oil) -- the +N/-N column at the right edge is :OilGit

Everything else: the shell. `h git` lists the aliases.

==============================================================================
DEBUGGING CODE                                        *dotfiles-workflows-debug*

See the error on the current line:~
    <C-w>d          (Neovim's built-in diagnostic float)

Jump to next / previous error:~
    ]d / [d

See all errors in the project:~
    :Trouble diagnostics

==============================================================================
SPLITS AND WINDOWS                                    *dotfiles-workflows-splits*

Open file in vertical split:~
    In Telescope: <C-v>
    Or: :vsp filename

Open file in horizontal split:~
    In Telescope: <C-x>
    Or: :sp filename

Move between splits:~
    <C-h/j/k/l>

Make splits equal size:~
    <C-w>=

Close other splits:~
    <C-w>o

==============================================================================
SEARCH AND REPLACE                                    *dotfiles-workflows-replace*

Replace in current file:~
    :%s/old/new/gc
    (g = all occurrences, c = confirm each)

Replace in project:~
    :FindReplace old new
    (Confirms each replacement)

Find files containing text:~
    :Find keyword
    Then :args to see the list

==============================================================================
CLIPBOARD                                            *dotfiles-workflows-clipboard*

Copy entire file:~
    :%y (goes to the system clipboard, OSC52 over ssh/WSL)

Copy to system clipboard:~
    Select text -> y (clipboard is synced; a notification confirms it)

Paste from system clipboard:~
    p

==============================================================================
MAINTENANCE                                        *dotfiles-workflows-maintenance*

Update plugins:~
    :Lazy update

Check plugin status:~
    :Lazy

Install/update LSP servers:~
    Not from inside the editor -- see |dotfiles-commands-servers|.
    Native:  make install nvim
    JS ones: make -C nvim servers

Check health:~
    :checkhealth

Find mappings I never use:~
    :KeymapUsage            (zeros first; see |dotfiles-commands-usage|)

Nuclear reset (reinstall everything):~
    :ResetNvim (then restart Neovim)

Regenerate help tags after editing docs:~
    :helptags ~/.config/nvim/doc
