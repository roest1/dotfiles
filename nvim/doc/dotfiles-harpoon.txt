*dotfiles-harpoon.txt*    Harpoon Notes

How Harpoon is used here. This extends, not replaces, `:help harpoon`.

==============================================================================
Overview~                                                       *dotfiles-harpoon*

Harpoon keeps a short list of files for the task in hand and jumps between
them. Think browser tabs for code, or a focus list, rather than a project
tree.

==============================================================================
Keymaps~                                                *dotfiles-harpoon-keymaps*

Location: lua/external/plugins/harpoon.lua

    <leader>a       Add the current file to the list
    <C-e>           Open the quick menu
    <C-n>           Next file
    <C-p>           Previous file

The quick menu is a buffer: delete a line to drop a file, move lines to
reorder, close it to apply. That is also how the list is cleared -- there is
no separate reset mapping any more (the leader-h-r one went in 37fa6ce).

==============================================================================
Workflow~                                              *dotfiles-harpoon-workflow*

    1. Open the 3-6 files the task touches
    2. <leader>a on each one
    3. <C-n> / <C-p> to cycle through just those
    4. <C-e>, delete the lines, close -- when the task is done

The list persists across sessions, per project directory.
